# Love Loop - A Forever Story 🌸💖

A cinematic, interactive story experience built with **React**, **Vite**, and **Framer Motion**. This project was designed as a premium, digital gift to celebrate a beautiful relationship journey.

![Love Loop Preview](/public/images/preview.png)

## ✨ Features

-   **Cinematic Storytelling:** 20-slide interactive narrative with smooth morphing transitions.
-   **Sakura Breeze Physics:** Custom particle system with falling pink petals and wind effects.
-   **Immersive Audio:** Hidden background music player that auto-starts on interaction (`theme.mp3`).
-   **Interactive Elements:**
    -   **Love Timer:** A live counter tracking years, days, hours, and seconds since the journey began.
    -   **Magic Cursor:** A trail of floating hearts follows your every move.
    -   **3D Tilt Cards:** The story card reacts to mouse movement for a premium feel.
-   **Mobile Responsive:** Fully optimized layout for seamless viewing on phones and tablets.

## 🛠️ Tech Stack

-   **Frontend Framework:** [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
-   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
-   **Animations:** [Framer Motion](https://www.framer.com/motion/)
-   **Icons:** [Lucide React](https://lucide.dev/)

## 🚀 How to Run Locally

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/dev69-code/love-loop.git
    cd love-loop
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Start the development server:**
    ```bash
    npm run dev
    ```

4.  **Open in Browser:**
    Go to `http://localhost:5173`.

## 🎵 Customization

-   **Music:** Place your favorite song as `theme.mp3` in the `public/music/` folder.
-   **Images:** Update `src/data/story.js` and add photos to `public/images/` to tell your own story.

## 💝 Deployment

This project is optimized for deployment on **Vercel**:
1.  Push to GitHub.
2.  Import project in Vercel.
3.  Deploy!
